# Facemap · 아기별 관측소

아이를 기다리는 부모와 아이를 키우는 부모를 위한 새로운 서비스 제안입니다. 얼굴이 잘 나온 입체 초음파 사진을 참고해 아기의 모습을 사실적인 사진처럼 먼저 만나보고, 기다리는 시간을 추억으로 간직하는 경험을 제안합니다.

## 핵심 경험

1. 진료 중 이미 받은 사진에서 얼굴이 잘 보이는 입체 초음파 사진을 선택합니다.
2. 사진에 보이는 얼굴 특징을 참고한 사실적인 아기 이미지를 만납니다.
3. 마음에 드는 이미지를 앨범과 기념 카드로 간직합니다.
4. 같은 아기 얼굴을 참고한 우주·동화·계절 콘셉트를 별똥별로 엽니다.

소행성 별똥별마켓의 신규 서비스로 제안하며, 얼굴을 먼저 만나는 경험이 핵심이고 콘셉트 사진은 후속 기능입니다. 별똥별은 돈이 아니라 소행성에서 소통하며 쌓는 포인트입니다. 이 포인트로 첫 얼굴 서비스와 추가 콘셉트를 엽니다. 각 3조각는 확정 정책이 아닌 데모용 차감 수량이며, 예시 미리보기에는 포인트를 사용하지 않습니다.

## 현재 프로토타입

- 가상 아기 ‘별이’의 사진 같은 AI 예시 이미지 4종
- 사진 없이 예시 확인, 사진 등록 UI, 체험용 소통포인트 적립 화면
- 콘셉트 확인, 브라우저 앨범 저장, PNG 기념 카드 다운로드
- 모바일 화면 대응

**현재 데모는 초음파를 분석하거나 아기 얼굴을 생성하지 않습니다.** 준비된 가상 아기 이미지를 보여줍니다. 실제 출생 후 외모와 닮는 정도는 검증되지 않았으며 외모 예측 정확도를 약속하지 않습니다. 실제 의료 정보·사진은 저장소에 포함하지 않습니다.

## 실행

Node.js 설치 후 의존성 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4174 를 엽니다. 정적 호스팅의 게시 디렉터리는 `prototype`입니다.

## 구현 범위와 다음 단계

실제 서비스에서는 초음파 입력 품질 안내, 이미지 생성 모델 연결과 얼굴 특징 보존 평가, 동의·보관·삭제 정책, 계정과 소통포인트 적립·사용 연동을 구현해야 합니다. 현재 사진 등록은 외부 전송 없이 브라우저에서만 처리하며, 앨범 메타데이터는 해당 브라우저의 localStorage에 저장됩니다.

예시 이미지는 내장 image_gen으로 제작했습니다. 생성 프롬프트는 `prototype/assets/generation-prompts.json`에 있습니다.

## 디자인 기준

[별똥별마켓](https://ssmarket.thelittlepla.net/web/)과 [출산·육아 체크리스트](https://ssmarket.thelittlepla.net/web/checklist.php)의 화이트·크림·베이지 및 브라운 포인트를 참고했습니다. 마켓의 포인트 단위인 ‘조각’을 사용합니다.

## 출생 이후: 미래의 너

아이가 태어나면 초음파나 출생 전 상상 이미지 대신 실제 아이 사진을 새로 등록합니다. 이 사진을 참고해 성인이 된 모습을 상상하는 두 번째 서비스를 별똥별로 엽니다. 화면은 현재 나이와 실제 사진을 받으며, 시연 결과는 독립적으로 만든 가상 성인 예시입니다. 실제 외모 예측 모델이나 사진 변환 API는 아직 연결하지 않았습니다. 출생 전 상상 카드와 출생 후 실제 사진을 구분해 관리하는 앨범은 후속 구현 범위입니다.
